Connect Stripe

Seven steps. Four of them you paste into a terminal; three you click on Stripe's website. At the end, every payment shows up on your board by itself.

0 of 7 done

Two free things you need first

  • →Node.js installed on your computer. Download it, click through, done.
  • →A Cloudflare account. This is where your Stripe key will live, safely away from the website.

Then open Terminal (Mac) or PowerShell (Windows). It's a window where you paste the lines below and press Enter. That's all you'll do with it.

One thing that trips everyone up: the terminal is always "standing" in some folder, and cd means walk into. So cd Downloads only works if you're one step above it. Writing cd ~/Downloads instead — with the squiggle — always works, wherever you are. Every command here uses the squiggle.

  1. 1

    Put the code on your computer

    First, actually download it. Find the lead-tech-fulfillment.bundle file in our chat and click it, so it lands in your Downloads folder. Nothing below works until it's there.

    Then check it arrived — paste this and press Enter:

    ls ~/Downloads/*.bundle

    You should see a filename. If it says no matches found, it hasn't downloaded yet — go back and click the file first.

    Now paste this. It finds the file whatever it ended up being called, even if your Mac added a (1):

    cd ~/Downloads
git clone "$(ls -t *.bundle | head -1)" lead-tech-fulfillment
cd lead-tech-fulfillment
npm install

    The last line takes a minute. Lots of text scrolls past — that's normal.

  2. 2
    You paste this

    Start the setup

    One line. It will do most of the work and stop twice to ask you something.

    npm run setup

    A browser window will open asking you to sign in to Cloudflare. Sign in, click Allow, then come back to the terminal — it carries on by itself.

    If it stops and tells you to run npx wrangler login, do exactly that, finish it in the browser, then run npm run setup again. It picks up where it left off.

    You click this in Stripe

    Fetch your Stripe key

    The terminal is now waiting, asking you to paste a key. Go and get it:

    In Stripe, click Developers → API keys → copy the Secret key. It starts with sk_.

    Paste it into the terminal and press Enter. You'll see stars instead of letters — that's on purpose, so nobody reading over your shoulder gets it.

  4. 4
    You click this in Stripe

    Tell Stripe where to send payments

    The terminal now prints a web address and a list of six events. Keep it visible — you're about to copy from it.

    In Stripe, click Developers → Webhooks → Add endpoint.
    Paste the address the terminal printed into Endpoint URL.
    Tick the six events it listed. Click Add endpoint.

    This is the part that makes payments arrive on their own. You're telling Stripe: when someone pays me, knock on this door.

  5. 5
    You click this in Stripe

    Copy the secret Stripe just made

    Right after you saved that, Stripe shows a code on the page.

    Find Signing secret and click Reveal. Copy the code — it starts with whsec_.

    Paste it into the terminal and press Enter. This is how your relay knows a knock really came from Stripe and not from a stranger.

    Make your login

    The terminal has now printed a long line starting with SYNC_TOKEN=. Copy that exact line and paste it back in. It will ask you to pick a password — this is the password you'll use to sign in every day.

    Do the same for anyone else who needs in, changing the email and name.

    Right now the dashboard only exists on your laptop. These two lines build it and put it on the internet, so your assistant can open it too.

    Cloudflare prints a link at the end. That link is your dashboard. Save it, and send it to whoever works the orders.

How to know it worked

Open your dashboard link, sign in, and click Settings. You're looking for one line:

Stripe is pushing payments here

Green means done. The next time someone pays you, their order lands on the board in about fifteen seconds, with nobody pressing anything.

Practise before real money moves

In Stripe there's a Test mode toggle at the top right. Flip it on and do the whole thing above with the test key — everything behaves normally, but no real money moves. Once you're happy, run npm run setup again with the real key.

If something goes wrong

"repository 'lead-tech-fulfillment.bundle' does not exist"
The file isn't in your Downloads folder. Either it never downloaded — go back to the chat and click it — or it landed somewhere else. ls ~/Downloads/*.bundle tells you which.
"cd: no such file or directory: Downloads"
You're already inside Downloads, so there's no Downloads within it to walk into. Use cd ~/Downloads — that works from anywhere.
"You need to register a workers.dev subdomain"
Your Cloudflare account has never run one of these before, so it doesn't have a name yet. The terminal prints a link — open it, pick any name (yours works fine), save. Then run npm run setup again; it keeps everything already done.
"it's necessary to set a CLOUDFLARE_API_TOKEN"
You're not signed in to Cloudflare yet. Run npx wrangler login, finish it in the browser, then npm run setup again.
The terminal says "command not found: npm"
Node.js isn't installed yet, or the terminal was open before you installed it. Install it, close the terminal, open a new one, try again.
Settings doesn't say "Stripe is pushing payments here"
The signing secret from step 5 didn't reach the relay. Run npm run setup again — it skips what's already done and re-asks for that.
Nothing appears when a payment comes in
In Stripe, open Developers → Webhooks and click your endpoint. It lists every attempt. A red 400 means the signing secret doesn't match — redo step 5.
Orders arrive but say "Unmapped"
Normal at first. Open Products and paste each product's Stripe ID in, so orders know which lane they belong to.
